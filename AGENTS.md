# Notes for AI agents (Codex, Cursor, v0, Copilot, Claude and others)

[CLAUDE.md](CLAUDE.md) holds the rules and applies to every agent. In short: work on a branch and never push to or merge into `main`; never deploy; never write agent log entries; no secrets; no Twitter/X sources; table, route or shape changes need both humans and a row in [docs/CONTRACT.md](docs/CONTRACT.md); stay on the free tiers; test data is synthetic. Run `npm run preflight` (and `npm test` for bigger changes) and report the exact result.

Skills are plain Markdown and work in any tool: open the one that fits the task in `agent-kit/skills/<name>/SKILL.md`, and its `references/` only when it says to. MCP clients can load them on demand from `agent-kit/mcp/server.js`; see [agent-kit/README.md](agent-kit/README.md) for every runtime.
