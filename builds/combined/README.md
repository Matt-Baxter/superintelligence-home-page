## Key Capabilities

1. **Next.js 16.4 + React 19 + TypeScript + Zod Foundation** (from Build A) with progressive-enhancement HTML forms AND JSON API endpoints.
2. **Hierarchical Superintelligence Ontology + Context-Disambiguated Scope Gate** (unified from Build A + Build B): 9 canonical shared-spec topics, 19 child sub-topics rolling up with `via` lineage, 23 organizations, 24 benchmarks with numeric/time-horizon score extraction, 37 watched researchers, and negative disambiguation rules preventing modality-alignment and narrow applied-AI noise.
3. **Dual-Layer Significance + 3-Tier Vercel AI Gateway Cascade**: Free deterministic 0–100 point-by-point `analysis` breakdown (`Evidence`, `Coverage`, `Update Type`, `Benchmarks`, `Frontier Signals`, `Capability Areas`, `Researchers`) paired with AI SDK 6 `Tier 0 → Tier 1 → Tier 2` assessment.
4. **22 Public Sources + Resumable 2023–Present Archive Backfill**: Fault-isolated `Promise.allSettled` feed ingestion, transactional `arxiv:` > `doi:` > `url:` > `title:` deduplication, first-seen coverage-lag tracking, and cursorable archive history tasks.
5. **Defense-in-Depth Accounts & Ownership**: Salted `scrypt` password hashing, constant-time anti-enumeration login, `SHA-256` hashed session tokens in `httpOnly` cookies, auth rate-limiting + bot honeypot, baseline security headers, and strict session-scoped votes/saves (`403` on cross-user tamper attempts).
6. **Full Research & Audit Suite**: Main Feed (`/`), Topic Filter + Named Presets + URL State, Story Provenance (`/stories/[id]`), Weekly Intelligence Brief (`/brief`), Source Health & OPML (`/sources`), Public Judge Audit Ledger (`/review`), Saved Stories + JSON/CSV Export (`/saved`), and Atom 1.0 syndication (`/api/feed.atom`).
