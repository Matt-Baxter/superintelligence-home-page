# UI, UX and navigation review (Nov 9, 2026)

Branch `feature/ui-review-2026-11-09`, from `feature/john-combined-2026-11-10` (2b9377f). Method: the extended site with
sample data, signed in as admin, every page the navigation offers (23) captured at 1280×800 and 390×844, an axe-core
scan (WCAG 2 A/AA plus best practices), and layout facts per page (headings, buttons, tap targets under 24px, sideways
overflow at phone width, console errors, load time). The capture script is `test/_ui-capture.js` (review tooling,
not part of the suite).

Baseline that holds up: every page loads (200, about 1.1 to 1.3 s on sample data), no console errors, no sideways
scroll on phones, one h1 per page, and the accessibility scan is mostly clean.

## Fixed on this branch

| # | Finding (evidence) | Fix |
| --- | --- | --- |
| 1 | **Flat, overloaded navigation.** 13 top-level links in one row (Feed, Capabilities, Map, Learn, Glossary, Lab, Saved, Weekly brief, Reading lists, Sources, Arena, Review, Journal) plus an Admin menu; reader pages and research tools mixed. | Nav entries declare a group (`ui.nav` gains `group`; the kernel now passes it through). The bar shows the six reading pages, then one **Research** menu and the Admin menu. On phones the open menu shows Research as a labelled section, like Admin. |
| 2 | **Two pages called "Map"** (the knowledge map and the code map), and the admin control room labelled "Research". | Unique labels: Knowledge map, Code map, Control room, Review desk. |
| 3 | **Breadcrumbs contradicted the nav.** Research pages linked their "Research" crumb to `/m/map`; the control room's crumb said "Administration / Research". The grouping lived in a regex that only the page directory used. | Breadcrumbs and the page directory read the declared group (regex kept only as a fallback). Research has no landing page, so its crumb is the section name, not a link to one of its pages. |
| 4 | **Admin's tab row mixed tabs with link-buttons** (Project workspace →, Studio →, Decide →), wrapping to two lines, and failing axe `aria-required-children` (critical): a tablist containing non-tabs. | Removed the three link-buttons (all three are in the Admin menu). The violation is gone. |
| 5 | **Unexplained score on every story card** (a boxed "18"). Screen readers got "18 out of 100"; sighted readers got a bare number. | The badge shows "/100" (CSS, so its text stays the score) and a tooltip explaining it opens the reasons. |
| 6 | **Card actions misaligned:** "Notes" (an inline link) and "Save" (a 36px button) sat at different heights. | Both share one height and centre line (44px on phones). |
| 7 | **Internal details shown to users:** the project's empty state named `docs/OUR_PARTS.md`; Arena listed experiments under raw ids (`concept:recursive-self-improvement`). | Plain wording; concept names instead of ids. |

Checks after the changes: preflight passed; the accessibility scan has no new findings (a contrast failure introduced
mid-change by a faded "/100" was caught by the scan and fixed); browser tests below.

## Still open, ranked

1. **Three navigation systems on most pages:** the bar, breadcrumbs and the "Browse pages" directory (the Project
   page adds its own sidebar). With grouped menus the directory is mostly redundant. It stays for now because two
   browser suites depend on it; decide whether it becomes a "Find a page" search inside the menus.
2. **Research has no landing page.** A short hub (what each tool is for, in reading order: Learn, Glossary,
   Knowledge map, Capabilities, Lab, Arena, Review desk, Topic dossiers) would give the section a front door and the
   breadcrumb a target.
3. **Concept map is unusable on a phone** (Learn): tiny nodes, crossing lines, 19 tap targets under 24px. Offer a
   list view by default under 640px.
4. **Small tap targets:** Knowledge map 49, Glossary 36, Learn 19, Weekly brief 14 under 24px.
5. **Arena's main control is raw JSON.** Generate form fields from each runner's params (they already have min, max,
   step and descriptions), keep JSON as an advanced tab.
6. **Admin overview:** 12 equal-weight counters, most zero. Lead with "Needs attention" and the two or three numbers
   that change decisions; collapse the rest.
7. **Inconsistent page widths:** most pages use the centred column; Project and Arena go full-bleed.
8. **Learn's breadcrumb shows the active tab** ("Concept map") while the heading and nav say "Learn".
9. **Story meta on phones wraps badly** (the source kind orphaned on its own line).
10. Remaining axe items: heading-order on Weekly brief, Arena, Control room and Code map; empty table headers on
    Decide; Project's main landmark and region structure; nested interactive controls on Learn.
11. **Type scale:** up to 11 distinct font sizes on a page (Capabilities). A fixed scale of five or six would steady it.
