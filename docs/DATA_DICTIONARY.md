# Data dictionary and controlled vocabulary

Generated by `node scripts/dictionary.js gen`. Edit the canonical registries, not this file.

Schema 1.3.0; ontology 4; concepts 3; glossary 1.1.0.

This backend reference joins existing schema fields, identifier namespaces and controlled terms. It does not publish a new site feature, approve proposed requirements, establish scientific support or assert that dynamic database records exist.

Canonical sources: [types](../schema/types.json), [ID grammar](../lib/ids.js), [ontology](../lib/ontology.json), [concepts](../modules/learn/data/concepts.json), [glossary](../modules/learn/data/glossary.json).

## Identifier namespaces

| Namespace | Meaning |
| --- | --- |
| `benchmark:` | a benchmark (lib/ontology.json benchmarks) |
| `concept:` | a Learn concept (modules/learn/data/concepts.json) |
| `doc:` | a reviewed paper, article or comment (modules/review; a hash of its title and text) |
| `event:` | a dated forecast record (modules/review; a hash of sentence and due date) |
| `lab:` | a registered toy experiment referenced by evidence dossiers |
| `module:` | a plug-in module (modules/<id>) |
| `org:` | an organisation (lib/ontology.json organizations) |
| `outlet:` | a publication hostname or pooled source class (never a person) |
| `person:` | a watchlist entry (lib/ontology.json people) |
| `req:` | a requirement in the shared spec (REQ-001) |
| `source:` | a source row (numeric id) |
| `story:` | a story row (numeric id) |
| `term:` | a sourced glossary term, symbol or function (modules/learn/data/glossary.json) |
| `topic:` | an ontology topic (lib/ontology.json topics) |

Static vocabulary lookup resolves only entries listed below. Record namespaces such as story, source, doc, event and outlet require their owning repository to establish existence. Literal alias lookup preserves Greek mathematical case; wildcard matching terms are documented verbatim and are not expanded by this lookup. An alias may legitimately match multiple entries or namespaces.

Coverage is the existing knowledge-layer schema, not every database column or CMS contract. Other build interfaces remain documented in [INTERFACES.md](INTERFACES.md).

External publication keys (arxiv:, doi:, url:) belong to PublicationIdentity, not Tag.qid namespaces. Compound chunk:<story>:<ord> embedding/evidence locators and registry file paths are provenance strings, not Tag.qid values. The qualified-ID grammar applies to declared identity fields, not every trace string.

## Enumerations

- **PublicationKind:** `arxiv`, `doi`, `url`, `unresolved`. Syntactically recognized publication link; never a claim of verified existence or evidence quality
- **ResolutionStatus:** `resolved`, `ambiguous`, `unresolved`. Static vocabulary resolution retains uncertainty rather than choosing an arbitrary alias match
- **Namespace:** `topic`, `org`, `benchmark`, `person`, `concept`, `req`, `module`, `source`, `story`, `term`, `doc`, `event`, `outlet`, `lab`. Namespaces of qualified ids (lib/ids.js)
- **TagMethod:** `ontology-term`, `entity`, `concept-term`, `embedding`, `rule`, `human`, `glossary-mention`. How a tag was made
- **ScopeRule:** `strong`, `topics`, `none`. Which part of the REQ-003 rule decided

## Term properties and source pointers

Notation follows the source author; formulas are conventions, not executable expressions. Properties state assumptions and caveats, not independent scientific verification.

### term:attention

Combines value vectors using weights derived from query–key scores.

Convention: Attention(Q,K,V) = softmax(QKᵀ / √dₖ)V

- The scale uses the key dimension in the original formulation.

Caveat: Attention weights alone are not a causal explanation of a model.

- [Attention Is All You Need, original paper](https://arxiv.org/abs/1706.03762)

### term:entropy

Summarizes uncertainty in a probability distribution.

Convention: H(p) = −Σᵢ pᵢ log pᵢ

- The logarithm base sets the unit.

Caveat: Higher uncertainty is not the same as more useful knowledge.

- [Deep Learning, chapter 3: probability and information](https://www.deeplearningbook.org/contents/prob.html)

### term:expectation

A probability-weighted average of a random quantity.

Convention: E[X] = Σₓ x p(x) (discrete case)

- Expectation is linear when the expectations exist.

Caveat: The average need not be an outcome you actually observe.

- [Stanford CS229: probability review](https://cs229.stanford.edu/section/cs229-prob.pdf)

### term:exponential

The natural exponential raises the constant e to a real-valued input.

Convention: exp(x) = eˣ

- Positive for finite real inputs in exact arithmetic.

Caveat: Direct floating-point evaluation can overflow; the explorer uses stable formulas.

- [Deep Learning, chapter 6: feedforward networks](https://www.deeplearningbook.org/contents/mlp.html)

### term:gradient

Collects the partial derivatives of a scalar function.

Convention: ∇f(x) = (∂f/∂x₁, …, ∂f/∂xₙ)

- Its coordinates describe local first-order change.

Caveat: A local direction does not guarantee finding the best solution.

- [Stanford CS229: linear algebra and matrix calculus](https://cs229.stanford.edu/section/cs229-linalg.pdf)

### term:intersection

The outcomes shared by two events.

Convention: A ∩ B

- An outcome belongs to both events.

Caveat: The intersection is an event, not a probability until a probability measure is applied.

- [Stanford CS229: probability review](https://cs229.stanford.edu/section/cs229-prob.pdf)

### term:jepa

A JEPA predicts a target representation from a representation of context, rather than rebuilding raw pixels. The representation is a learned collection of numbers, not a guarantee of understanding.

Convention: context embedding → predictor → target embedding

- JEPA objectives compare predicted and target embeddings. Avoiding representation collapse and choosing informative context/targets are important design issues; image representation learning, action-free video prediction and action-conditioned planning are different evaluations.

Caveat: A research mechanism, not a demonstration of superintelligence. Check the original paper and its evaluation conditions.

- [I-JEPA: original paper](https://arxiv.org/abs/2301.08243)
- [V-JEPA 2](https://arxiv.org/abs/2506.09985)
- [V-JEPA 2.1](https://arxiv.org/abs/2603.14482)
- [LeJEPA](https://arxiv.org/abs/2511.08544)

### term:kl-divergence

Compares two distributions through expected log probability ratios.

Convention: D_KL(p || q) = Σᵢ pᵢ log(pᵢ/qᵢ)

- Generally asymmetric.
- Nonnegative when defined; can be infinite.

Caveat: It is not a symmetric distance metric.

- [Deep Learning, chapter 3: probability and information](https://www.deeplearningbook.org/contents/prob.html)

### term:latent-reasoning

Some systems keep intermediate computation in hidden vectors instead of spelling every step as text. That can change how compute is used, but does not automatically make the result correct or interpretable.

Convention: intermediate hidden states → task output

- Continuous hidden-state computation differs from a visible chain of thought. Claims need task-specific and compute-matched evaluation; an internal trajectory should not be assumed to be a faithful explanation, nor all latent methods assumed to use recurrent depth.

Caveat: A research mechanism, not a demonstration of superintelligence. Check the original paper and its evaluation conditions.

- [Continuous latent reasoning (Coconut)](https://arxiv.org/abs/2412.06769)
- [Recurrent depth](https://arxiv.org/abs/2502.05171)

### term:logarithm

The inverse of exponentiation for a specified base.

Convention: ln(exp(x)) = x

- The real natural logarithm needs a positive argument.

Caveat: The base determines the scale; do not assume every paper uses the same base.

- [Deep Learning, chapter 6: feedforward networks](https://www.deeplearningbook.org/contents/mlp.html)

### term:loss

Measures an error or objective that training tries to reduce.

Convention: L(θ)

- The definition determines what counts as a better fit.

Caveat: Lower training loss alone does not establish safety or generalization.

- [Deep Learning, chapter 6: feedforward networks](https://www.deeplearningbook.org/contents/mlp.html)

### term:parameters

The letter theta often names adjustable model parameters.

Convention: f(x; θ)

- A model can have many parameter coordinates.

Caveat: Theta can mean something else; check the paper’s definitions.

- [Deep Learning, chapter 6: feedforward networks](https://www.deeplearningbook.org/contents/mlp.html)

### term:partial-derivative

Rate of change in one input coordinate while holding the other coordinates fixed.

Convention: ∂f / ∂xᵢ

- Requires the relevant derivative to exist.

Caveat: A partial derivative is a local quantity, not a causal effect.

- [Stanford CS229: linear algebra and matrix calculus](https://cs229.stanford.edu/section/cs229-linalg.pdf)

### term:probability

Probability of an event after conditioning on another event.

Convention: P(A|B) = P(A ∩ B) / P(B)

- The event B must have positive probability in this formula.

Caveat: Conditioning does not by itself establish causation.

- [Stanford CS229: probability review](https://cs229.stanford.edu/section/cs229-prob.pdf)

### term:query-key-value

Attention compares queries with keys to weight the corresponding value representations.

Convention: QKᵀ scores → softmax weights → weighted V

- Query and key inner dimensions must agree.

Caveat: These are representation roles, not a guarantee of a faithful database lookup.

- [Attention Is All You Need, original paper](https://arxiv.org/abs/1706.03762)

### term:recurrent-depth

A model can apply a shared processing block repeatedly to refine its hidden state. Extra passes spend inference compute without necessarily writing a longer reasoning trace.

Convention: hₖ₊₁ = Fθ(hₖ, context), with shared θ

- Weight-tied depth recurrence refines latent states. It is distinct from recurrence across sequence time and from modifying learned weights. Compare accuracy at matched compute, latency and memory, and evaluate stopping criteria and out-of-distribution behavior.

Caveat: A research mechanism, not a demonstration of superintelligence. Check the original paper and its evaluation conditions.

- [Recurrent depth: original paper](https://arxiv.org/abs/2502.05171)
- [Depth-Recurrent Attention Mixture (Dreamer)](https://arxiv.org/abs/2601.21582)
- [Recurrent-Depth VLA](https://arxiv.org/abs/2602.07845)

### term:sigma

An overloaded symbol: it can indicate standard deviation or a sigmoid function.

Convention: Meaning depends on the surrounding definition.

- No single meaning is safe to infer from the symbol alone.

Caveat: Follow the author’s notation rather than choosing a meaning automatically.

- [Stanford CS229: probability review](https://cs229.stanford.edu/section/cs229-prob.pdf)

### term:sigmoid

Maps one real number to a value between zero and one.

Convention: σ(x) = 1 / (1 + exp(−x))

- Increasing input never decreases output.
- σ(−x) = 1 − σ(x).

Caveat: The output is not automatically a trustworthy probability.

- [Deep Learning, chapter 6: feedforward networks](https://www.deeplearningbook.org/contents/mlp.html)

### term:softmax

Converts a list of scores into nonnegative weights that total one.

Convention: softmax(z)ᵢ = exp(zᵢ) / Σⱼ exp(zⱼ)

- Outputs total one.
- Adding the same constant to every input leaves the result unchanged.

Caveat: Large weights are not evidence of calibrated confidence.

- [Deep Learning, chapter 6: feedforward networks](https://www.deeplearningbook.org/contents/mlp.html)

### term:square-root

The nonnegative real root whose square equals a nonnegative input.

Convention: (√x)² = x, x ≥ 0

- The displayed principal real root is nonnegative.

Caveat: Negative real inputs require a different number system or convention.

- [Stanford CS229: linear algebra and matrix calculus](https://cs229.stanford.edu/section/cs229-linalg.pdf)

### term:summation

Adds the terms indexed below and above a sum sign.

Convention: Σᵢ aᵢ

- The index tells you which terms are added.

Caveat: A finite sum and an infinite series have different assumptions.

- [Stanford CS229: linear algebra and matrix calculus](https://cs229.stanford.edu/section/cs229-linalg.pdf)

### term:transformer

An architecture built around attention and other neural-network components.

Convention: token representations → attention and feedforward blocks

- The original model uses multiple attention heads.

Caveat: An architecture label alone does not establish capabilities or safety.

- [Attention Is All You Need, original paper](https://arxiv.org/abs/1706.03762)

### term:transpose

Swaps a matrix’s row and column indices.

Convention: (Aᵀ)ᵢⱼ = Aⱼᵢ

- Transposing twice returns the original matrix.

Caveat: Transpose is different from inverse and from conjugate transpose.

- [Stanford CS229: linear algebra and matrix calculus](https://cs229.stanford.edu/section/cs229-linalg.pdf)

### term:variance

Measures expected squared distance from a mean.

Convention: Var(X) = E[(X − E[X])²]

- Nonnegative when defined.

Caveat: Small variance does not establish a correct mean or an unbiased measurement.

- [Stanford CS229: probability review](https://cs229.stanford.edu/section/cs229-prob.pdf)

### term:vectors

A vector holds indexed values; a matrix arranges indexed values in rows and columns.

Convention: x ∈ ℝⁿ; A ∈ ℝᵐˣⁿ

- Matrix multiplication requires compatible inner dimensions.

Caveat: A representation’s shape does not tell you what its values mean.

- [Stanford CS229: linear algebra and matrix calculus](https://cs229.stanford.edu/section/cs229-linalg.pdf)

### term:world-models

A world model predicts selected aspects of an environment and its changes. It may help planning, but can be wrong when actions or situations differ from training.

Convention: state representation + action → predicted next representation

- Separate observational representation learning from action-conditioned dynamics and closed-loop control. Check interventions, rollout error, distribution shift, safety constraints and whether planning results transfer beyond the evaluated environments.

Caveat: A research mechanism, not a demonstration of superintelligence. Check the original paper and its evaluation conditions.

- [V-JEPA 2](https://arxiv.org/abs/2506.09985)
- [V-JEPA 2.1](https://arxiv.org/abs/2603.14482)
