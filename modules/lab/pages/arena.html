Arena

Edit an experiment, a policy or a rule, run it in a sandbox in your browser, compare it head to head, then apply the winner. The sandbox is a Web Worker running only the Lab's deterministic code: no network, no page access, and it's stopped after a time limit. Applying a change goes back to the server, which checks it again.
