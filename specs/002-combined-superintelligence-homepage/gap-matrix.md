# Empirical Gap Matrix & Best-of-Both Selection (Build A vs. Build B → Combined Build)

**Date:** 2026-11-23  
**Inputs:** `CONTRACT.md` v1.0, `specs/001-superintelligence-homepage/spec.md`, `.specify/memory/constitution.md`, live headless browser & multi-model judge run (`builds/john/bakeoff/runs/2026-11-23T03-48-51/{analysis.json,judges.json}`), and full code inspection of `builds/matt/` (Build A) and `builds/john/` (Build B).

## 1. Executive Synthesis

Neither Build A nor Build B alone wins cleanly across every criterion in `CONTRACT.md` Section 5:

- **Build A (`builds/matt/`, Claude Code + Spec Kit)** excelled at **architectural simplicity, modern TypeScript/Next.js 16 SSR ergonomics, cryptographic session hygiene, resumable 2023–present archive backfilling, and a public `/review` audit ledger**, but **failed `AT-13` outright** (missing the `REQ-017` topic filter on the feed), had **64.3% rule-tagger recall/precision on its live sample** due to a flat phrase table without sub-topic hierarchy, depended on a **single paid Anthropic API key** (`JUDGE=off` when absent), lacked **per-story multi-source provenance pages**, and shipped **empty `next.config.ts` security headers** with no auth rate-limiting.
- **Build B (`builds/john/`, v0)** excelled at **ontological depth (hierarchical 28-topic tree, 23 organizations, 24 benchmarks with score extraction, 37 watched researchers), deterministic 0–100 explainable significance scoring, 3-tier free-first Vercel AI Gateway assessment cascade, story coverage-lag provenance, weekly intelligence brief, source health + OPML/Atom portability, and rate-limit/bot guards**, but suffered from **applied-ML false positives in live arXiv ingestion** (e.g., modality/visual "alignment", medical imaging, sentiment dialogues, water governance polluting `?topic=alignment`), **non-semantic card markup** (navigation links scraped as story titles in `REPORT.md`), **buried sign-up UI** (`AT-07` probe `reachable: false`), **unhashed session tokens in DB**, and **high CJS/Express custom-kernel complexity** hurting maintainability.

The **Combined Build (`builds/combined/`)** adopts Build A's clean Next.js 16 + React 19 + TypeScript + Zod + progressive-enhancement foundation and grafts onto it Build B's hierarchical ontology, precision-hardened scope gate, deterministic 0–100 significance breakdown, 3-tier Vercel AI Gateway judge cascade, story provenance view, weekly brief, and security guards—while closing every gap discovered on both sides.

## 3. Gaps Explicitly Verified & Closed

1. **Gap A1 (Build A `AT-13` Failure — Missing Topic Filter):** Resolved by first-class `?topic=<id>` server filtering across all 9 shared-spec topics (including child-topic rollup) with mobile-friendly pill navigation and empty-topic messaging.
2. **Gap A2 (Build A `JUDGE=off` Degradation):** Resolved by always computing the deterministic 0–100 explainable significance score (`lib/analysis.ts`) at ingest time, with the 3-tier AI Gateway judge (`lib/assess.ts`) layering calibrated 1.0–10.0 AI assessments on top when available.
3. **Gap A3 (Build A Missing Security Headers & Rate Limits):** Resolved via `next.config.ts` baseline security headers (`X-Content-Type-Options`, `Referrer-Policy`, `Strict-Transport-Security`, `X-Frame-Options: SAMEORIGIN`, `Permissions-Policy`) plus per-IP auth rate limiting and honeypot validation.
4. **Gap B1 (Build B Applied-ML & Modality-Alignment False Positives):** Resolved by `lib/ontology.ts` context disambiguation (rejecting visual/cross-modal/sequence alignment, non-AI safety/governance, and narrow medical/avatar/retail applications unless paired with frontier/AGI signals).
5. **Gap B2 (Build B Non-Semantic Story Links & Buried Signup):** Resolved by rendering every feed item as `<article class="story" data-story-id="..." data-published="...">` with `<h2><a href="...">` for the original link, inline `<ul class="topics">` with `(matched: ...)`, `<ul class="sources">`, and top-level `/signup` and `/signin` routes.
6. **Gap B3 (Build B Unhashed Session Tokens):** Resolved by storing only `sha256(cookieToken)` in `sessions.token_hash` with `httpOnly`, `sameSite: "lax"`, `secure` cookies and 30-day persistence.
